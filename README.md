# LoveMed — Medical Card of Love

v0.1 prototype for SillyTavern.

Medical terminology:
- Pulse → Карта пациента / Медицинские показатели
- Spark → Реактивность / Спонтанная реакция
- NPC → Сопутствующие лица
- Journal → История наблюдений
- Model → Служебная диагностика
- Card scan → Анамнез

The relationship state is stored per current chat/character.
The user's custom preference library is stored separately in localStorage and survives character changes.

Install by placing the LoveMed folder into the user's SillyTavern extensions directory, then reload SillyTavern.
